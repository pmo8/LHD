## 🚀 Hướng Dẫn Sử Dụng & Xem Trang Web

1. **Cách 1: Mở trực tiếp bằng trình duyệt**
   - Nhấp đúp chuột vào file `index.html` (hoặc chuột phải chọn **Open with > Chrome / Edge / Firefox**).

2. **Cách 2: Chạy qua máy chủ web cục bộ (Node.js)**
   ```bash
   npx serve .
   # hoặc
   npx http-server -p 8080
   ```
   Sau đó mở trình duyệt tại: `http://localhost:8080`
